# Principios de Diseño Visual

## Elementos de diseño visual

Los bloques de construcción son línea, forma, color, textura, espacio, forma/volumen (form) y tipografía. Cada uno se elige y se estiliza a propósito, no al azar: las formas geométricas transmiten formalidad, las orgánicas transmiten calidez; la textura llama la atención pero satura rápido si se abusa de ella; el espacio en blanco reduce la carga cognitiva.

## Principios de diseño visual

- **Jerarquía:** qué se procesa primero — se logra con tamaño, color, posición.
- **Contraste:** hace que un elemento resalte — útil para diferenciar acciones (ej: un botón "Eliminar" en rojo vs. uno "Guardar" en otro color).
- **Balance:** distribución equilibrada de elementos, no necesariamente simétrica.
- **Escala:** el tamaño relativo entre objetos comunica su importancia relativa.
- **Dominancia:** un elemento se vuelve el punto focal de la página.
- **Unidad:** todos los elementos se sienten parte de un mismo conjunto coherente.

## Principios de Gestalt

Definidos por los psicólogos alemanes Max Wertheimer, Kurt Koffka y Wolfgang Köhler en la década de 1920 — describen cómo el cerebro organiza la información visual de forma automática:

- **Figura-fondo:** distinguir intuitivamente qué es el elemento principal y qué es el fondo.
- **Similitud:** objetos con apariencia parecida se perciben como relacionados (ej: íconos de alineación de texto, todos con el mismo estilo visual).
- **Proximidad:** objetos cercanos entre sí se perciben como un grupo relacionado.
- **Continuidad:** el ojo sigue líneas y curvas, agrupando lo que está alineado.
- **Cierre (closure):** el cerebro completa formas incompletas (ej: una línea punteada se percibe como una sola línea continua).

## Layouts efectivos

**Patrones de lectura F y Z:** los ojos siguen un patrón predecible según cómo esté organizado el contenido — útil para decidir dónde poner lo más importante.

**Layouts comunes:**
- **Grid:** ideal para muchos elementos similares (ej: catálogo de productos).
- **Columna única:** ideal para contenido con mucho texto (ej: un blog).
- **Split-screen:** divide la pantalla en dos secciones bien diferenciadas.

**Grillas de layout:** columnas (límites verticales), filas (límites horizontales), o grillas uniformes (ambos). Para desktop, 12 columnas es un estándar común; para mobile, 4-6 columnas. Conviene aplicar la grilla recién en alta fidelidad — en baja o media fidelidad el diseño todavía está cambiando demasiado como para preocuparse por la alineación exacta.
